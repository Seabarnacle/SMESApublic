{\large Supporting information for \emph{Secondary Minimal Error Sampling Algorithms for Accelerating Self-Consistent Field Calculations}}\par\vspace{0.2in}
Paul Calistrate-Petre and Yan Alexander Wang\par\vspace{0.5in}
\begin{minipage}{0.78\textwidth}\large
This document records the Cartesian geometry and starting calculation settings for every case input in \texttt{mesa/SMESACASES}. Coordinates are in angstrom. Inputs supplied as Z-matrices were converted to the matching Cartesian representation by Psi4. Values marked ``default'' are supplied by \texttt{metarunner.py} when the case file does not override them.
\end{minipage}
